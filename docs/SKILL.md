# Agent skill (canonical)

The FastAPI Factory Utilities agent skill lives in the
[DeerHide/agent_skills](https://github.com/DeerHide/agent_skills) repository:

https://github.com/DeerHide/agent_skills/tree/main/skills/fastapi-factory-utilities

Install or update local agent skills with:

```bash
curl -fsSL https://raw.githubusercontent.com/DeerHide/agent_skills/main/scripts/install_or_update.sh | bash
# or, after install:
deerhide_agents_skills_update
```

Do not keep a vendored copy of the skill in this repository.
